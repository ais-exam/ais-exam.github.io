Principles

  1. 01

    Real scientific questions

    Each exam is built on a question that scientists are still working to answer.

  2. 02

    Scientific validation

    What an agent produces is checked the way a field checks new results, against data and its established standards.

  3. 03

    New insights from agents

    Each exam starts from what a field already knows and asks what an agent’s approach can add to it.

About

AI's Exam is a collection of exams for AI, starting with climate science and vision. Each topic poses its own problem with its own data, tasks and evaluation, and each has its own page with the full results.
